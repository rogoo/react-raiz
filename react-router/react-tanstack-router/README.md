## Using Tanstack Router
Aqui estou utilizando o **Tanstack Router**, definindo rotas baseadas no arquivo.

Criei um serviço utilizando a lib **redaxios** (uma versão light da axios que usa a Fetch API) para acessar o famoso https://jsonplaceholder.typicode.com.  O serviço é utilizado no componente Posts para poder simular a chamada de outro componente usando rotas usando parametros.

Achei bacana ambas libs (tanto Tanstack Router como readaxios).
