## React Monorepo
Um projeto bem simples para testar monorepo no VS Code.

São três projetos: um ***Header***, ***Main*** e um ***Footer***. Assim como um projeto usual, se alguns dos projetos é atualizado, automaticamente o projeto é atualizado no browser.

Achei bacana a extensão **Monorepo Workspace**, facilitou bem.

### O que é legal?
O compartilhamento de configurações do ESlint e bibliotecas (do node_modules).

### Próxima diversão?
Provavelmente se divertir com **Turborepo**.
