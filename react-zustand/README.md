### React e Zustand

Projeto simples de contador usando React/Zustand.

O component **Counter** utiliza o create básico do Zustand, já o **CounterPersist** utiliza o persist do **\*zustand/middleware** para salvar no _localstore_ o valor da variável count.

O component **ChildUm** foi criado apenas para compartilhar o código do counter do hook **_useCounterSotre_**.

O component **ChildDois** só para garantir que não esta sendo compilado. Como não existe state no component **App**, e ele não depende da variavél count, de boas.
